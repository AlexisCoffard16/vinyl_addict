# Vinyl'Addict
## Mon premier projet
Ce que vous pouvez voir au-dessus sont les fichiers qui représentent mon tout premier projet : un site de vente de vinyles complet en HTML/CSS/JS/PHP et, avec le logiciel XAMPP qui me permet d'avoir un serveur qui l'héberge (Apache), de connecter ma base de données (MySQL), et de pouvoir la gérer avec phpMyAdmin.
